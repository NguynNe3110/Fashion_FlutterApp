lib/

│   │   │       ├── boxes/              # Định nghĩa tên các Box (VD: settingBox, cacheBox)

│   │   │   
│   │   ├── datasources/                # LocalDataSource implementations

│   │
│   ├── mappers/                    # ⭐ QUAN TRỌNG: Extension functions để map DTO -> Entity
│   │   ├── user_mapper.dart        # Ví dụ: UserResponseDto.toEntity()
│   │   └── ...
│   │
│   ├── repositories/               # Implementations của domain repositories
│   └── session/                    # Quản lý Token, User Session (Map data/session)
