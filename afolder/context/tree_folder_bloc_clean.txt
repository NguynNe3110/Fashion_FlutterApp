## SƠ ĐỒ MỐI QUAN HỆ GIỮA CÁC MODULES

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         MODULE DEPENDENCY GRAPH                              │
└─────────────────────────────────────────────────────────────────────────────┘

                                    ┌─────────────┐
                                    │  resources  │ ◄── Localization (i18n)
                                    │    (🟠)     │
                                    └──────┬──────┘
                                           │
                                           ▼
    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                     │
    │    ┌─────────────┐     import     ┌─────────────┐                  │
    │    │   shared   │ ◄──────────────│    app     │                  │
    │    │   (🟢)     │                │   (🔴)     │                  │
    │    └──────┬─────┘                └──────┬─────┘                  │
    │           │                              │                          │
    │           ▼                              ▼                          │
    │    ┌─────────────┐                ┌─────────────┐                 │
    │    │   domain    │ ─────────────► │    data     │                 │
    │    │   (🟣)     │ implement       │   (🔵)     │                 │
    │    └──────┬─────┘                └──────┬─────┘                 │
    │           │                              │                          │
    │           ▼                              ▼                          │
    └─────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
                           ┌─────────────┐
                           │ initializer │ ◄── Khởi tạo app
                           │   (🟡)     │
                           └─────────────┘
```

## MÔ TẢ CHI TIẾT TỪNG MODULE

| Module | Màu | Trách nhiệm chính | Phụ thuộc |
|--------|-----|-------------------|-----------|
| **shared** | 🟢 | Utils, Constants, DI, Helpers, Exceptions, Mixins | (độc lập) |
| **domain** | 🟣 | Entities, Repository interfaces, Use Cases, Navigation interfaces | (độc lập) |
| **data** | 🔵 | Repository impl, API (Dio), DB, Preferences | domain, shared |
| **app** | 🔴 | UI screens, BLoC, Navigation impl, Resources | shared, domain, resources |
| **initializer** | 🟡 | Quản lý thứ tự khởi tạo app | shared, data, domain, app |
| **resources** | 🟠 | Localization (l10n) | (độc lập) |

## QUY TẮC PHỤ THUỘC

```
✅ ĐƯỢC PHÉP:
  app     → shared, domain, resources
  data    → domain, shared
  shared  → (độc lập)
  domain  → (độc lập)
  initializer → shared, data, domain, app
  resources → (độc lập)

❌ KHÔNG ĐƯỢC PHÉP:
  • Chỉ `app` được phép implement Navigation
```

## CÁC CONVENTION ĐẶT TÊN

| Loại | Pattern | Ví dụ |
|------|---------|-------|
| File Dart | snake_case | `home_page.dart`, `app_bloc.dart` |
| Class | PascalCase | `HomePage`, `AppBloc`, `HomeEvent` |
| Private member | _camelCase | `_myVariable`, `_handleTap()` |
| Constant | camelCase hoặc SCREAMING_SNAKE | `maxWidth`, `API_TIMEOUT` |
| Folder | snake_case | `home`, `common_view`, `app_bloc` |
| Generated file | *.gr.dart | `app_router.gr.dart` |
| API model | *data.dart | `api_user_data.dart` |
| Local model | *data.dart | `local_user_data.dart` |
| Mapper | *mapper.dart | `api_user_data_mapper.dart` |

## LỢI ÍCH CỦA CẤU TRÚC NÀY

1. **Separation of Concerns** - Mỗi layer/module có trách nhiệm rõ ràng
2. **Testability** - BLoC, Repository, UseCase đều có interface, dễ mock
3. **Scalability** - Thêm feature mới chỉ cần tạo folder trong `ui/`
4. **Maintainability** - Thay đổi một phần không ảnh hưởng các phần khác
5. **Reusability** - `common_view`, `shared` có thể share giữa các feature
6. **Team Collaboration** - Nhiều người có thể làm việc trên các feature khác nhau song song
